QUESTION — RDS AND SECURITY GROUP SYNTAX
Student asked what RDS is and whether the database security group is defined
as cdk_lab_vpc and allows 3306 from the web-server group.
Answer: Amazon Relational Database Service is a managed relational database
service; this assignment uses its MySQL engine. AWS handles infrastructure
management tasks; EC2 hosts the web servers while RDS hosts the database.
vpc=cdk_lab_vpc places the security group inside that VPC; the group is not
the VPC. ec2.SecurityGroup(...) constructs the group, stored in the Python
variable database_security_group. add_ingress_rule(...) adds an incoming rule:
source=web_server_security_group, port=TCP 3306, final string=description.
The source identifies network interfaces associated with that group, not a
public IP range. The database group must later be attached to the RDS instance.
Network permission does not replace database username/password authentication.
No source changes or new student mistake; next step remains RDS subnet group.

QUESTION — WHAT DOES CDK DIFF DO?
Explained that cdk diff compares the locally synthesized infrastructure
definition with the deployed CloudFormation stack and shows additions,
changes, removals, and possible replacements. An undeployed stack appears
as new resources. It does not deploy changes; by default it may create a
read-only CloudFormation change set to assess replacement accurately.
Contrast: synth generates template; diff previews changes; deploy applies them.
